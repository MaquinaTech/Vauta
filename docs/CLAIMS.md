# What backs each claim

Every factual claim in the [README](../README.md) ([Español](../README.es.md)) is listed here with what supports it:
an automated **test** (run `swift test`, or the filter shown), a **benchmark** ([BENCHMARKS.md](BENCHMARKS.md)), or a
**verification command** you can run yourself. A claim that has none of these is not made in the README; where the
only support is the code itself (a design rule that no test pins down), this page says so.

Run all the tests with:

```sh
swift test -Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing
```

and a single suite with `--filter "<suite or test name>"`. Test files are in `Tests/VautaCoreTests/` unless noted.

## Not claimed

The reproducible numbers are those in [BENCHMARKS.md](BENCHMARKS.md), except its harness-phase minutes row, which comes from a sealed test set, one LLM rater with no human review, and every switch on (Apple's model ships a subset that was not judged as such; the integrated model runs the judged request).
- Better quality of Apple's outcome-first summary or of Apple's Ask harness: the summary covered more outcomes but had more factual errors, and Ask gave more correct answers but fewer refusals when the question could not be answered and more invented answers, so the summary stays the old one (since 2026-10-24) and Ask stays off: its comparison was re-run with the query translator in both arms and judged blind (correct answers 65.6% against 49.5%, but invented answers 19.3% against 12.2%, and fewer refusals of unanswerable questions, 79% against 87%; the judge recommends holding it; [LANGUAGE_MODEL.md](LANGUAGE_MODEL.md#harness-phase-what-ships-blind-test-2026-10-24)). The figures of the harness phase come from a sealed test set that is not in this repository, graded by one LLM rater with no human review; the gold labels were also model-assisted, and the judge was of the same model family that wrote the gold labels and the fixtures, so judge bias cannot be ruled out.
- That Vauta works in a given conferencing app until [COMPATIBILITY.md](COMPATIBILITY.md) says **Verified** for it.
- Accuracy on real Spanish meetings or in any language other than English and the Spanish read speech and synthetic conversations of [BENCHMARKS.md](BENCHMARKS.md#spanish); on real phone or speakerphone calls; or with overlapping speech beyond what [BENCHMARKS.md](BENCHMARKS.md) measures.

- That Vauta has been independently audited. It has not; see [SECURITY.md](../SECURITY.md).
